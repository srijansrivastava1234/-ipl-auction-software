9. TOP MENTOR QUESTIONS & HOW TO ANSWER CONFIDENTLY
--------------------------------------------------------------------------------
Q1: Where is the JWT token stored and how is it attached to API requests?
Ans: When a user logs in via Login.jsx, the backend returns a signed JWT token which 
     we store in browser localStorage. For all subsequent API requests, Axios extracts 
     this token and injects it into the HTTP headers as: Authorization: Bearer <token>.

Q2: Why did you build the UI with Vanilla CSS instead of Tailwind or Bootstrap?
Ans: Using Vanilla CSS with custom CSS variables allowed us 100% fine-grained mathematical 
     control over our bespoke circular Orbit Arena transforms, complex backdrop-filter 
     glassmorphism, and franchise-specific dynamic neon glow animations without the bundle 
     bloat of external UI frameworks.

Q3: How does the frontend handle real-time bid updates from other teams?
Ans: The application connects to the Spring Boot WebSocket broker via StompJS on /ws-auction. 
     When any team places a bid, the backend broadcasts to /topic/bids. App.jsx intercepts 
     this message, updates the active bid price state, shifts the halo in OrbitArena, and 
     updates the purse balance in the Leaderboard without requiring a full page refresh.

Q4: How does the UI prevent accidental invalid bids?
Ans: BiddingConsole.jsx checks the team's remaining budget against the calculated next bid. 
     If the increment exceeds the remaining purse, the button is automatically disabled 
     with a warning tooltip. Additionally, if the current team already holds the highest bid, 
     bid buttons are temporarily deactivated to prevent self-outbidding.
