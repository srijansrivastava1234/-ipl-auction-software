3. DEEP-DIVE COMPONENT WALKTHROUGH (COMPONENT-BY-COMPONENT)
================================================================================

Mentor: "Open your React components and explain how data flows into the UI."

--------------------------------------------------------------------------------
A. `src/App.jsx` (The Main Dashboard Controller)
--------------------------------------------------------------------------------
- Purpose: Root application component managing global state and network sync.
- State Hooks:
  * `const [user, setUser] = useState(null)` -> Active logged-in user profile & JWT token.
  * `const [players, setPlayers] = useState([])` -> All registered auction players.
  * `const [teams, setTeams] = useState([])` -> 10 franchise states with updated purses.
  * `const [currentIndex, setCurrentIndex] = useState(0)` -> Active player spotlight index.
  * `const [activeHighestBid, setActiveHighestBid] = useState(null)` -> Real-time winning bid.
  * `const [timerSeconds, setTimerSeconds] = useState(15.00)` -> Live countdown timer.
- Lifecycle & WebSocket Sync (`useEffect`):
  * Mounts SockJS & StompClient to `http://localhost:8082/ws-auction`.
  * Subscribes to `/topic/bids`: On message received, updates `activeHighestBid`, shifts 
    the neon halo in Orbit Arena, and updates team purse in local state.
  * Subscribes to `/topic/players`: On player sold or unsold, re-fetches latest rosters.

--------------------------------------------------------------------------------
B. `src/components/OrbitArena.jsx` (Circular Stadium Visualization)
--------------------------------------------------------------------------------
- Mathematical Layout Calculation:
  ```jsx
  const total = teams.length;
  const radius = 240; // Orbit radius in pixels
  const angle = (index / total) * (2 * Math.PI) - Math.PI / 2;
  const x = Math.cos(angle) * radius;
  const y = Math.sin(angle) * radius;
  ```
- Dynamic Styling:
  * Applies `transform: translate(${x}px, ${y}px)` to position each team badge.
  * If `team.id === activeHighestBid?.teamId`, attaches CSS class `orbit-node active-bidder` 
    triggering a multi-layered neon glow wave animation in the team's official color.

--------------------------------------------------------------------------------
C. `src/components/BiddingConsole.jsx` (Interactive Action Panel)
--------------------------------------------------------------------------------
- Key Features:
  1. Quick Increment Triggers:
     * `+ ₹20 Lakhs` (`baseAmount + 2,000,000`)
     * `+ ₹50 Lakhs` (`baseAmount + 5,000,000`)
     * `+ ₹1.00 Crore` (`baseAmount + 10,000,000`)
  2. Custom Bid Input: Allows exact decimal input with automatic formatting into Crores/Lakhs.
  3. Safety Disablers:
     * Disables when `user.role !== 'ROLE_TEAM_OWNER'`.
     * Disables when `proposedAmount > userTeam.budget`.
     * Disables when `activeHighestBid?.teamId === userTeam.id` (Anti-self outbid).
  4. Calls `axios.post('/api/bids', { playerId, teamId, amount }, { headers: { Authorization } })`.

6. COMPLETE TECHNICAL DEFENSE (WHY WE CHOSE THIS STACK)
================================================================================

- Why Vite over create-react-app or Next.js for this project?
  * `create-react-app` is deprecated and slow. Next.js is designed for server-side SEO rendering, 
    which adds unnecessary complexity for an internal, live-state dashboard. Vite uses native 
    ES modules in development for instant startup (sub-300ms HMR) and optimized Rollup bundling.
- Why Vanilla Modern CSS over Tailwind?
  * Bespoke radial mathematics (Orbit Arena transforms), complex CSS keyframe glow pulses, 
    and HSL dynamic runtime theme variables are much cleaner and more maintainable in standard 
    CSS without fighting utility class clutter.

7. EXHAUSTIVE MENTOR Q&A / VIVA DEFENSE PREPARATION
================================================================================

Q1: How does the frontend attach the JWT token to HTTP requests?
Answer:
"When the user logs in via `Login.jsx`, the backend returns a JWT token which we persist in 
`sessionStorage`. Whenever we send an API request with Axios, we attach the token to the headers 
as `Authorization: Bearer ${token}`. If no token is present, the request is blocked by backend security."

Q2: How does OrbitArena calculate the circular positions of the 10 franchises?
Answer:
"In `OrbitArena.jsx`, we calculate the trigonometric angle for each team index:
`const angle = (index / totalTeams) * (2 * Math.PI) - Math.PI / 2;`
We then compute Cartesian coordinates:
`const x = Math.cos(angle) * radius;`
`const y = Math.sin(angle) * radius;`
And render each node with dynamic CSS: `transform: translate(${x}px, ${y}px)`."

Q3: How do you prevent rapid clicking from sending multiple duplicate bids?
Answer:
"In `BiddingConsole.jsx`, when a bid button is clicked, we immediately set a local loading state 
`isSubmitting = true` which disables all bid buttons until the Axios promise resolves. Additionally, 
if the team is already the highest bidder, the buttons remain disabled by checking 
`activeHighestBid?.teamId === currentTeam.id`."

Q4: What happens on the UI when a WebSocket message arrives from `/topic/bids`?
Answer:
"The Stomp client listener in `App.jsx` parses the JSON bid payload, updates the `activeHighestBid` 
state, updates the corresponding player's current price in the player list, and subtracts the 
potential purse in the leaderboard. React's reactive virtual DOM then updates the affected components 
in under 16 milliseconds without any full page reload."
